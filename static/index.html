日食・太陽面通過 精密計算機

JPL DE440 暦にもとづく高精度計算 ・ 地上の地点と人工衛星からの見え方

1計算する現象

「地球の影」は、観測者が人工衛星・探査機のときだけ計算します。

2どこから見るか（観測者）

CelesTrak から最新の軌道要素（TLE）を取得して SGP4 で軌道を計算します。

永年変化率（任意）

元期の平均赤道（J2 が軌道を回す赤道）に対する平均の変化率です。空欄の項目は軌道要素から J2 の式で計算します（薄い字がその値）。

GCRS（J2000赤道）基準の平均要素。J2 による歳差は元期の平均赤道のまわりで計算し、太陽同期の傾斜角と昇交点の地方時も元期の平均赤道を基準にします。計画中・仮想の衛星の検討向けです。 TLE の要素は SGP4 専用の平均要素（TEME 基準）なので、「TLE貼付」から入力してください。

JPL Horizons の探査機・衛星の精密軌道を使います（例: -170 JWST、-21 SOHO、-125544 ISS）。地球近傍の衛星は刻みを 1〜2 分に。

NASA SSCWeb（衛星状況センター）が公開している科学衛星の過去の軌道（おもに 1 分間隔）を使います。CelesTrak からは最新の TLE しか取れないため、過去に衛星から見えた日食・太陽面通過を調べるときに使います（例: hinode ひので、iris、iss）。軌道データのない期間は自動的に除きます。

CCSDS（宇宙データシステム諮問委員会）の国際標準の形式で、JAXA などの宇宙機関が軌道の受け渡しに使っています。OEM（軌道暦）は書かれた状態を補間し、OPM・OCM の状態ベクトルは数値積分（地球の重力場・太陽と月の引力、値があれば大気抵抗・太陽輻射圧と軌道制御）で伝搬し、OMM（平均要素）は SGP4 で、TDM（追跡データ）は観測局の位置を添えて軌道を決めてから計算します。KVN・XML（複数のメッセージをまとめた NDM も可）に対応し、OMM は CelesTrak の JSON・CSV も読めます。

地球上のどこかで見られる日食をすべて探し、皆既帯・金環帯の経路や部分食が見える範囲を地図で表示します。 太陽面通過は地球中心から見た接触時刻（世界共通の標準値）を計算します。地図をクリックすると、その地点での見え方を計算できます。

4詳細設定 （精度・モデル）

ようこそ

左の設定で ①現象・②観測者・③期間 を選んで「計算する」を押すと、見られる日食や太陽面通過の一覧が表示されます。 一覧の行をクリックすると、欠け方の動画・グラフ・地図などの詳しい結果を確認できます。 「結果を保存」で保存したファイルは から、あとで同じ画面で見返せます。

  • 高精度: JPL DE440 暦、光行時間・ΔT・地球楕円体（WGS84）を厳密に扱い、接触時刻を 0.1 ms まで追い込みます。
  • 人工衛星から: TLE（SGP4）、軌道要素、静止衛星、JPL Horizons の探査機軌道、NASA SSCWeb の過去軌道、CCSDS の軌道データメッセージ（OEM・OPM・OMM・OCM）と追跡データメッセージ（TDM）に対応。地球に隠される時間も考慮します。
  • 地図: 皆既帯・金環帯の経路と限界線、部分食の食分分布、太陽面通過の可視地域を表示します。

使い方と用語

    
基本の流れ

    
    
      
  1. 計算したい現象（日食・水星・金星）にチェックを入れます。
    2. 
      
  2. 観測者を選びます。「地上の地点」は緯度・経度・標高、「人工衛星」は NORAD 番号・TLE・軌道要素・静止経度・JPL Horizons ID・NASA SSCWeb の衛星 ID・CCSDS のメッセージで指定します。打ち上げ前の衛星は「軌道要素」に計画値を入れ、「平均近点角を変えて一括計算」を使うと、衛星が軌道上のどこにいても起こりうる結果の範囲が分かります。「地球全体」は世界のどこかで見られる現象を探します。
    3. 
      
  3. 期間を指定して「計算する」。一覧の行をクリックすると詳細が開きます。
    4. 
    

    
CCSDS のメッセージ

    
「人工衛星」の「CCSDS」に、CCSDS の軌道データメッセージ（OEM・OPM・OMM・OCM）や追跡データメッセージ（TDM）を貼り付けるか、ファイルを開きます。OEM は書かれた状態を補間し、OPM と OCM の状態ベクトルは数値積分で軌道を伝搬し、OMM は SGP4 で計算します。TDM には観測局の位置が書かれていないため、衛星以外の参加者（観測局）の緯度・経度・標高を入力すると、角度・距離・ドップラーの観測から軌道を決めて計算します（同じ衛星の OPM・OMM・TLE を一緒に入れると、それを初期値にします）。「内容を確認」で、読み取った内容と軌道の大きさを計算の前に確かめられます。

    
地球の影

    
「計算する現象」の「地球の影」にチェックを入れて観測者を「人工衛星」にすると、衛星から見て太陽が地球に隠れる時間（衛星が地球の影に入る時間）を周回ごとに計算します。影の季節（影に入る周回が続く期間）と、周回ごとに太陽が欠け始める・中心が隠れる・完全に隠れる時刻とその逆、長さ、影の中央の衛星直下点を表示します。地球の大気が太陽を隠す高さ（遮蔽高度）は波長で変わるため、「詳細設定」の遮蔽高度と比べる高さ（既定 0・140・250 km）ごとに季節と長さを並べます。日食・太陽面通過と一緒に計算でき、影に入る時期と長さは衛星が軌道上のどこにいてもほとんど変わりません。

    
結果の保存と見返し

    
一覧の「結果を保存」で、一覧と計算条件を JSON ファイルに保存します。上の「保存した結果を開く」でそのファイルを選ぶと、一覧が保存したときのまま表示され、左の設定も保存した条件に戻ります。
      一覧の行をクリックすると、保存した計算条件でその現象の詳細（接触時刻・動画・グラフ・地図）を計算し直して表示します。詳細の「データ」タブの「JSON をダウンロード」で保存した 1 件の現象や、cli.py の --format json の出力も開けます。

    
観測画像と比べる

    
詳細の「見え方（動画）」タブで向きを「太陽の北が上」にして「角度の目盛り」と「表示範囲」を選ぶと、ひので・SDO などの画像と同じ座標（太陽の中心からの X, Y、″）で見られます。「時刻を指定（UTC）」に画像の時刻を入れるとその時刻の値を、「観測画像と比べる」に画像ごとの時刻と測った位置を入れると計算との差（O−C）を表にします。概要の「半径による接触時刻の変化」には、太陽や天体の半径を変えたときに接触時刻がどれだけ変わるかを示します。

    
用語

    

      
食分
太陽の直径のうち月に隠された割合。皆既日食では 1 以上になります（地球全体の一覧では NASA と同じく中心食の場合は月と太陽の視直径比）。

      
食面積率
太陽の面積のうち隠された割合。体感的な暗さに近い指標です。

      
第1〜第4接触
月（惑星）の縁と太陽の縁が接する瞬間。第1接触＝欠け始め、第2接触＝皆既・金環（または内接）の始まり、第3接触＝その終わり、第4接触＝欠け終わり。

      
位置角 / 天頂角 V
太陽の中心から見た接触点の方向。位置角は天の北極方向から東回り、V は天頂方向から測った角度です。「太陽の北から」の位置角は、太陽の自転軸の北から東回りに測ります。

      
太陽の P 角・X, Y
P 角は、太陽の自転軸の北が天の北から東へ傾いている角度です。X, Y は太陽の北を上にしたときの太陽の中心からの角度（″、X は西、Y は北が正）で、ひので・SDO などの画像の座標（helioprojective）と同じです。

      
γ（ガンマ）
月の影の軸が地球中心から最も近づいたときの距離（地球赤道半径単位）。小さいほど地球の中央付近を影が通ります。

      
サロス番号
約18年周期で似た日食が繰り返す系列の番号。

      
ΔT
地球自転の不規則さを表す TT と UT の差。将来・過去ほど不確かで、主に食の見える場所（経度）に影響します。

      
TLE
人工衛星の軌道要素の標準形式。元期から離れるほど誤差が大きくなるため、衛星の予報は元期の前後数日が目安です。

    

    
精度について

    
    
      
  • 天体位置は JPL DE440（DE440s）暦、時刻系は IERS 観測値にもとづく ΔT を使用。接触時刻は光行時間を反復計算し、0.1 ms 以下まで収束させています。
    • 
      
  • 太陽の半径は、画像に見える太陽の縁（1 AU で 959.96″ = 696,231 km。ひので SOT が撮った 2006 年の水星の太陽面通過の接触を 1 秒ほどで再現）を既定にしています。IAU 2015 公称値（695,700 km）は光球（τ=1）の半径で、これを使うと太陽面通過の接触時刻が 10 秒ほど変わります。金星は大気があるため、可視光では 6131 km、軟 X 線では 6202 km の円盤に見えます（Reale ほか 2015）。
    • 
      
  • 月の縁の凹凸（山や谷）は考慮していません。NASA 方式の 2 種類の月半径でその平均的な効果を近似しています。実際の接触時刻は月縁地形により ±1〜2 秒ほど変わることがあります。
    • 
      
  • 人工衛星の精度は軌道情報の精度で決まります。TLE は元期から日数が経つと数 km〜数百 km の誤差を生じます。
